🎬 UMC Movie — 5주차 API 연결 화면

브라우저(fetch)에서 Spring Boot 백엔드의 API 3개를 직접 호출합니다.

현재 화면 출처(Origin):

① 닉네임 중복 체크

GET /members/nickname/{nickname} → { "available": boolean }

② 이메일 중복 체크

GET /members/email/{email} → { "available": boolean }

③ 유저별 평점 조회

GET /members/{memberId}/ratings?page=0&size=10 → RatingResponse[] (최신순)
